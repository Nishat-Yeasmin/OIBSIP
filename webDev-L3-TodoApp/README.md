# 📝 To-Do Web App

A simple and interactive To-Do Web Application built using **HTML5, CSS3, and Vanilla JavaScript**.
The application allows users to add, edit, complete, and delete daily tasks while keeping pending and completed tasks organized separately.

## 📌 Features

### Core Features

* ➕ Add new tasks
* 📋 Display newly added tasks in the **Pending Tasks** list
* ✅ Mark tasks as completed
* 🔄 Move completed tasks to the **Completed Tasks** list
* ✏️ Edit task text inline
* 🗑️ Delete tasks permanently
* 🔢 Display pending and completed task counts
* 💬 Friendly empty-state messages when there are no tasks

### Bonus Features

* 🕒 Display task creation timestamp
* ✅ Display task completion timestamp
* 💾 Save tasks using `localStorage`
* 🔄 Tasks remain available after refreshing the page
* 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

## 💡 How It Works

### Add Task

Enter a task in the input field and click **Add Task**. The task will immediately appear in the Pending Tasks section.

### Complete Task

Click the **Complete** button to move a task from Pending Tasks to Completed Tasks.

### Edit Task

Click the **Edit** button to modify the task text. Press **Enter** to save the changes.

### Delete Task

Click the **Delete** button to permanently remove a task.

### Task Persistence

Tasks are stored in the browser's `localStorage`, so they remain available even after refreshing the page.
